# 하단 검색

OPPO Pad Mini **OPD2515 / ColorOS 17 CN**에서 하단 길게 누르기로 Google 서클 투 서치 또는 선택한 앱을 여는 Android 앱입니다. 현재 버전은 **2.9.0 / 버전 코드 13**, 패키지는 `dev.padhelper.fastcts`입니다.

**APK를 태블릿에 설치해 사용합니다. Windows 설치 프로그램은 필요하지 않습니다.** 전체 사용법은 [HOW TO USE.MD](HOW%20TO%20USE.MD), 코드 구조는 [개발 안내](micts/fast-launch/README.md)를 참고하세요.

## 실행 방식 선택

| 앱 설정의 방식 | 동작과 준비 |
| --- | --- |
| **하단 영역 인식** — 기본값 | 하단 중앙 200dp × 38dp의 투명 터치 영역을 약 400ms 길게 누름. 접근성을 직접 승인하며, 보안 설정 쓰기는 선택 사항 |
| **ColorOS 기본 하단 바 · 로그 감지** | ColorOS 기본 바의 제스처와 애니메이션 사용. 접근성·보안 설정 쓰기·Breeno 비활성화 또는 미설치·별도 ADB 에이전트 활성화 필요 |

두 방식을 동시에 실행하지 않습니다. 기본 바 방식은 Breeno 화면을 열었다 닫는 예전 방식과 다릅니다. 비활성화된 Breeno 서비스 호출 시도를 시스템 로그에서 골라 검색으로 연결합니다. 해당 ROM 로그에 의존하므로 다른 기기·펌웨어는 별도 확인이 필요합니다.

## 설치와 기본 사용

1. `Bottom-Search-2.9.0.apk`와 `Bottom-Search-2.9.0.apk.sha256`을 받습니다. APK를 태블릿에서 직접 눌러 설치합니다.
2. Google LLC의 Google 앱과 [공식 MiCTS 2.6](https://github.com/parallelcc/MiCTS/releases/tag/v2.6)을 설치합니다. Google 서비스·Play 스토어가 필요한 환경을 먼저 준비하고, 음성 인식 서비스가 없다면 Speech Recognition & Synthesis도 설치합니다.
3. 앱의 **기본 어시스턴트 설정**에서 Google을 선택하고 화면 텍스트·스크린샷 사용을 허용합니다.
4. **사용 시작** 후 시스템 접근성의 하단 검색을 직접 켭니다. ColorOS의 제한된 설정이 표시되면 해당 앱의 앱 정보에서 시스템 안내에 따라 승인합니다.
5. 기본값인 **하단 영역 인식**에서 실제 하단 중앙을 길게 눌러 검색이 열리는지 확인합니다.

앱서랍 아이콘은 없습니다. **설정 → 앱 → 하단 검색 → 앱 추가 설정**, 접근성의 하단 검색 설정, 또는 빠른 설정 타일에서 다시 엽니다. 범위 표시·최근 앱 카드 표시·연결 앱 선택도 이 화면에 있습니다.

## ColorOS 기본 바 활성화

1. 접근성과 **WRITE_SECURE_SETTINGS(보안 설정 쓰기)**를 먼저 허용합니다. 앱의 **최초 ADB 설정 안내**에서 명령과 강한 권한의 설명을 확인합니다.
2. Breeno가 비활성화되어 있는지 확인합니다. 앱은 패키지를 자동으로 끄지 않습니다. 필요하면 본인 기기에서 원래 상태를 기록한 뒤 수동으로 설정합니다.
3. **ColorOS 기본 하단 바 · 로그 감지**를 선택하고 **기본 바 ADB 활성화 안내**를 엽니다.
4. 안내가 생성한 현재 설치본의 활성화 명령을 복사해 ADB가 있는 컴퓨터에서 실행합니다. 여러 기기를 연결했다면 `adb -s`로 대상을 지정합니다.
5. 앱에 기본 바 연결 상태가 표시되면 실제 제스처로 검색을 확인합니다.

**재부팅하거나 앱을 업데이트하면 ADB 활성화를 다시 해야 합니다.** 명령에는 현재 설치 APK 경로와 버전이 들어가므로 옛 명령을 재사용하지 않습니다. 에이전트가 연결된 동안에는 앱의 라디오 선택으로 두 방식을 전환할 수 있습니다. 완전히 끝내려면 **기본 바 에이전트 종료**를 누릅니다.

## 권한·실행 범위

일반 하단 영역 방식에는 접근성이 필요하고 보안 설정 쓰기는 선택 사항입니다. 기본 바 방식에는 보안 설정 쓰기와 ADB 셸 에이전트가 필요합니다. 앱이 이 권한이나 에이전트를 스스로 활성화하지 않습니다.

에이전트는 ADB 셸 UID 2000으로 실행하며 필터링한 시스템 로그를 대기해 읽습니다. 앱에 READ_LOGS를 부여하지 않고 원본 로그를 저장하거나 앱으로 전송하지 않습니다. DUMP 권한과 셸 UID로 보호한 등록 창구를 통해 Binder를 연결하고, 검증한 길게 누르기 신호와 세대·시각만 전달합니다. 양쪽은 호출 UID·프로토콜·앱 버전을 확인합니다.

화면 읽기·자체 캡처·음성·검색어 수집·제스처 주입·네트워크·일반 오버레이·포그라운드 서비스·상시 폴링은 사용하지 않습니다. 하단 영역 방식·꺼짐·잠금 상태에서는 로그 읽기를 중단하고 연결만 유지합니다. 연결 종료나 종료 명령은 로그 자식 프로세스를 정리하며 앱 재연결 대기는 최대 30초입니다. 장시간 전력 측정 결과는 아직 없습니다.

OEM 제스처 값은 실제 터치 창 연결 후 하단 영역에서 `0`, 기본 바 에이전트의 로그 수신 확인 후 `1`로 적용합니다. 방식 전환 중에도 처음 기록한 원래 값을 보존하고 **끄기**·접근성 해제 시 복원합니다. **앱 삭제 전 먼저 끄기를 누르세요.** 강제 종료·삭제 뒤 자동 복원은 보장하지 않습니다.

ColorOS가 ADB 권한 부여·회수를 거부할 수 있습니다. 전체 보안·전원 보호를 약화하는 우회는 하지 않습니다. 부팅 복구 옵션은 자기 접근성을 복구하는 기능이며 기본 바 에이전트의 재활성화를 대신하지 않습니다.

## 빌드와 배포

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\micts\fast-launch\Build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Test-AndroidRecovery.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Test-NativeBar.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Test-Release.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build-Release.ps1

# 앱 빌드부터 실행
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build-Release.ps1 -BuildApp
```

JDK 21과 Android SDK가 필요한 개발 명령입니다. 배포 결과는 **`dist/Bottom-Search-2.9.0.apk`와 `.apk.sha256`**입니다. `App-Release.json`의 검증 정보로 APK만 배포하며 PC GUI나 설치 ZIP은 포함하지 않습니다. GitHub 게시 작업은 별도입니다.

## 검증과 알려진 한계

2.9의 Android 복구·보안 147개, 이벤트 판별·시각 정책 67개, APK 배포 49개로 **263개 검사**를 통과했습니다. OPD2515에서 모두 닫기 후 실제 검색을 영역 방식 2회·기본 바 방식 3회 확인했고, UI 전환·서비스 재연결·로그 자식 종료 후 복구·종료 후 재활성화·화면 꺼짐/켜짐·전원 버튼 제외를 확인했습니다. 권한 없는 별도 앱의 Binder 등록·내부 검색·자동 설정 접근도 차단됐습니다.

재부팅 후 앱을 열기 전 접근성 복구, 셸 에이전트 부재, 에이전트 없이 영역 방식 사용, ADB 재활성화 후 기본 바 검색을 실기기로 확인했습니다. 새 기본 바 방식의 재부팅 후 ADB 재활성화 요구는 그대로입니다. 장시간 배터리와 다른 기기·펌웨어는 미검증입니다.

Google의 **화면에 관해 물어보기** 버튼 이후 지연은 별도 문제입니다. 확인한 Google 버전의 PNG 처리 지연은 이번 트리거 방식 선택으로 해결되지 않았고 **0.5초 이하 목표는 미해결**입니다. 상세 측정 범위와 다른 기기·장시간 배터리 미확인 항목은 사용 가이드에 있습니다.

기본 바 트리거 구성은 [ColorGoogle의 고정 버전](https://github.com/joeyandu/ColorGoogle/tree/38ead061d06d5f24b5ff20b92f58d5e4632a0298)을 참고해 별도 구현했습니다. 본 앱은 해당 소스 파일을 복사해 포함하지 않습니다.

이 저장소에는 현재 Android 앱의 소스·리소스·빌드 및 테스트 스크립트·문서만 포함합니다. 이전 Windows ADB GUI·앱 정리 도구·개인 백업·기기 로그·서명 키·APK는 포함하지 않습니다. 로컬 작업 폴더의 보관 자료는 삭제하지 않습니다.
