# 하단 검색

**하단 중앙을 길게 눌러 서클 투 서치를 실행하세요.**

OPPO Pad Mini에서 Google 서클 투 서치를 편하게 열 수 있도록 도와주는 Android 앱입니다. 서클 투 서치 대신 자주 사용하는 다른 앱을 연결할 수도 있습니다. 루팅 없이 사용할 수 있으며, 앱서랍에는 아이콘이 표시되지 않습니다.

[**APK 다운로드**](https://github.com/JngVedere/OPD2515_CST/releases/latest)

## 주요 기능

- 하단 중앙을 길게 눌러 서클 투 서치 실행
- **하단 영역 인식**과 **ColorOS 기본 하단 바** 중 실행 방식 선택
- 하단 인식 범위 미리 보기
- 최근 앱 목록에서 설정 화면 숨기기·보이기
- 길게 눌렀을 때 실행할 앱 직접 선택
- 빠른 설정 타일로 사용 켜기·끄기 및 설정 열기
- 선택 사항으로 재부팅 후 접근성 자동 복구

## 사용 환경

대상 기기는 **OPPO Pad Mini OPD2515 / ColorOS 17 중국 내수용**입니다. 다른 기기나 펌웨어에서는 동작이 다를 수 있습니다.

서클 투 서치를 사용하려면 다음 앱을 별도로 준비해주세요.

- **Google** — Google LLC에서 배포하는 앱
- **[MiCTS 2.6](https://github.com/parallelcc/MiCTS/releases/tag/v2.6)** — 서클 투 서치 실행에 필요

Google 서비스가 없는 기기는 먼저 기기의 Google 서비스와 Play 스토어를 준비해주세요. 음성 인식 서비스가 없다면 Google의 **Speech Recognition & Synthesis**도 설치해주세요.

## 설치 및 시작하기

1. [다운로드 페이지](https://github.com/JngVedere/OPD2515_CST/releases/latest)에서 **`Bottom-Search`로 시작하는 `.apk` 파일**을 받습니다.
2. 태블릿에서 APK를 열어 설치합니다. 설치가 차단되면 해당 파일을 연 앱의 **이 출처 허용**을 켭니다.
3. 아래의 **설정 다시 열기** 경로로 하단 검색 설정을 엽니다.
4. **기본 어시스턴트 설정**에서 Google을 선택하고, 화면 텍스트와 스크린샷 사용을 허용합니다.
5. **하단 영역 인식**을 선택한 뒤 **사용 시작**을 누릅니다.
6. 시스템 접근성 설정에서 **하단 검색**을 켭니다. ColorOS에서 제한된 설정 안내가 나오면 하단 검색의 앱 정보에서 안내에 따라 허용합니다.
7. 다른 앱을 연 상태에서 **화면 하단 중앙을 잠시 길게 누르면** 서클 투 서치가 실행됩니다.

기본 **하단 영역 인식** 방식은 태블릿에서 설정할 수 있습니다. 컴퓨터와 ADB가 필요한 기능은 아래에 별도로 안내합니다.

## 실행 방식 선택

| 방식 | 사용 방법 | 필요한 설정 |
| --- | --- | --- |
| **하단 영역 인식** · 기본값 | 하단 중앙의 투명한 인식 영역을 길게 누릅니다. | 접근성 허용 |
| **ColorOS 기본 하단 바 · 로그 감지** | ColorOS 기본 바의 제스처와 애니메이션을 사용합니다. | 접근성, 보안 설정 쓰기 권한, Breeno 비활성화, 컴퓨터에서 ADB 활성화 |

두 방식 중 하나를 선택해 사용합니다.

### ColorOS 기본 하단 바 사용하기

1. 앱의 **최초 ADB 설정 안내**를 열어 **보안 설정 쓰기 권한**을 허용합니다. 이 권한은 앱이 시스템 설정을 변경할 수 있는 강한 권한이므로 안내를 읽고 진행해주세요.
2. **ColorOS 기본 하단 바 · 로그 감지**를 선택합니다.
3. **기본 바 ADB 활성화 안내**를 열고 Breeno 상태를 확인합니다. Breeno가 켜져 있다면 안내에 따라 비활성화합니다. 앱이 자동으로 끄지는 않습니다.
4. USB 디버깅을 허용한 태블릿을 ADB가 준비된 컴퓨터에 연결합니다.
5. **활성화 명령 복사**로 복사한 명령을 컴퓨터에서 실행합니다.
6. 앱의 연결 상태를 확인한 뒤 기본 하단 바를 길게 누릅니다.

**태블릿을 재부팅하거나 하단 검색을 업데이트한 뒤에는 ADB 활성화가 다시 필요합니다.** 항상 현재 앱의 안내에서 명령을 새로 복사해주세요. 컴퓨터 없이 사용하려면 **하단 영역 인식**을 선택하세요.

Breeno를 비활성화하면 전원 버튼 등으로 Breeno를 여는 기능에도 영향을 줄 수 있습니다.

## 내게 맞게 설정하기

| 설정 | 설명 |
| --- | --- |
| **인식 영역 표시** | 설정 화면에서 하단 인식 범위를 파란색으로 보여줍니다. 설정을 벗어나면 다시 투명해집니다. 영역 크기를 바꾸는 기능은 아닙니다. |
| **최근 앱에 표시** | 하단 검색 설정 화면을 최근 앱 목록에 보이거나 숨깁니다. 앱서랍 아이콘에는 영향을 주지 않습니다. |
| **앱 선택** | 길게 눌렀을 때 실행할 앱을 고릅니다. 서클 투 서치로 돌아가려면 기본값을 선택하세요. |
| **재부팅 후 자동 복구** | 이전에 직접 켠 하단 검색의 접근성을 재부팅 직후 복구합니다. 최초 ADB 권한 설정이 필요하며, 기본 바 방식의 ADB 재활성화는 별도로 해야 합니다. |
| **사용 시작 / 끄기** | 선택한 실행 방식을 켜거나 끕니다. |

## 설정 다시 열기

앱서랍 아이콘을 숨긴 앱이므로 다음 경로 중 하나로 설정을 열 수 있습니다. 메뉴 이름은 기기 설정에 따라 조금 다를 수 있습니다.

- **설정 → 앱 → 앱 관리 → 하단 검색 → 앱 추가 설정**
- **설정 → 접근성 → 다운로드한 앱 → 하단 검색 → 설정**
- **빠른 설정의 하단 검색 타일 길게 누르기**

앱 설정의 **빠른 설정에 버튼 추가**를 눌러 타일을 추가해두면 편리합니다. 최근 앱에서 숨겨도 위 경로로 다시 열 수 있습니다.

## 알려진 한계

1. **실행 방식 → ColorOS 기본 하단 바 · 로그 감지**를 사용하는 경우, 태블릿을 재부팅하면 ADB 활성화 명령을 다시 실행해야 합니다. **하단 영역 인식** 방식에는 이 재활성화가 필요하지 않습니다.
2. 서클 투 서치(Circle to Search)의 **화면에 관해 물어보기**를 누르면 일부 화면에서 약 **2.8초**의 전환 지연이 발생할 수 있습니다. 지연 시간은 Google 앱과 화면 내용에 따라 달라질 수 있습니다.

## 자주 묻는 질문

**최근 앱에서 ‘모두 닫기’를 누른 뒤 반응하지 않아요.**

하단 검색의 접근성이 켜져 있는지 확인하고, 앱 설정의 **자동 실행 설정**과 **앱 정보와 절전 설정**에서 백그라운드 실행을 허용해주세요. 필요하면 **최근 앱 정리 제외 설정** 안내에 따라 최근 앱 카드를 잠근 뒤 다시 숨길 수 있습니다.

**재부팅한 뒤 작동하지 않아요.**

먼저 태블릿 잠금을 한 번 풀어주세요. 하단 영역 방식은 접근성 상태와 자동 복구 옵션을 확인하고, 기본 바 방식은 앱 안내의 ADB 활성화 명령을 다시 실행해주세요.

**MiCTS에 ‘Trigger failed’가 떠요.**

Google이 기본 디지털 어시스턴트로 선택되어 있는지, 화면 텍스트·스크린샷 사용이 허용되어 있는지 확인해주세요. 필요한 음성 인식 서비스도 설치한 뒤 MiCTS를 직접 열어보세요.

**‘화면에 관해 물어보기’로 넘어갈 때 느려요.**

Google 앱과 화면 내용에 따라 전환이 지연될 수 있습니다. 하단 검색에서 실행 방식을 바꿔도 이 지연이 해결되지는 않습니다.

**앱을 삭제하려면 어떻게 하나요?**

먼저 하단 검색 설정에서 **끄기**를 눌러 변경한 하단 바 설정을 복원해주세요. 기본 바 방식을 사용했다면 **기본 바 에이전트 종료**도 누른 뒤 앱을 삭제해주세요. 별도로 비활성화한 Breeno는 자동으로 복원되지 않습니다.

## 권한 안내

**접근성**은 하단 인식 영역과 실행 기능을 유지하는 데 사용합니다. 하단 검색 자체는 화면 내용을 읽거나 캡처하지 않습니다. 서클 투 서치의 화면 인식과 검색은 Google 앱이 처리합니다.

**보안 설정 쓰기**는 하단 영역 방식에서는 선택 사항이며, 재부팅 후 자동 복구와 하단 바 설정에 사용합니다. ColorOS 기본 바 방식에서는 이 권한과 별도 ADB 활성화가 필요합니다.
