# Circle-to-Search Trigger

> 다른 기기에서도 동작할 수 있으나, 동작을 보장하지 않습니다. 동작 테스트는 **OPPO Pad Mini OPD2515에서만** 진행했습니다.

**오포 패드 미니에서 Circle to Search와 Gemini Assistant를 사용해보세요.**

**🪶 APK 약 110KB — 1MB 미만의 초경량 앱입니다.** 상주 알림이나 백그라운드 폴링 없이 동작하며, 설정 화면을 닫으면 메모리 사용량도 약 50MB 수준입니다.

OPPO Pad Mini에서 Google 서클 투 서치를 편하게 열 수 있도록 도와주는 Android 앱입니다. 서클 투 서치 대신 자주 사용하는 다른 앱을 연결할 수도 있습니다. 루팅 없이 사용할 수 있으며, MiCTS 없이 서클 투 서치를 직접 실행합니다.
기존에 있던 다른 앱 대비 반응성과 User Experience에서의 자연스러움을 최대한 고려한 앱입니다.

[**APK 다운로드 (약 110KB)**](https://github.com/JngVedere/OPD2515_CST/releases/latest)

## 주요 기능

- 하단 중앙을 길게 눌러 서클 투 서치 실행 (3버튼 탐색에서는 홈 버튼 길게 누르기)
- **하단 영역 인식**과 **ColorOS 기본 하단 바** 중 실행 방식 선택
- 하단 인식 영역의 위치·크기, 길게 누르기 인식 시간 조절 (가로/세로 화면 따로)
- 앱 서랍 아이콘 **OpdCTS** — 누르면 설정 화면 (서클 투 서치나 Gemini Assistant로 바꿀 수 있음)
- 빠른 설정 타일 **Search**(서클 투 서치) / **Assistant**(Gemini Assistant)
- 최근 앱 목록에서 설정 화면 숨기기·보이기
- 길게 눌렀을 때 실행할 앱 직접 선택
- 빠른 설정 타일로 사용 켜기·끄기 및 설정 열기
- 선택 사항으로 재부팅 후 접근성 자동 복구
- 전원 버튼 길게 눌러 Gemini Assistant 호출
- 앱 안에서 업데이트 확인과 설치
- (선택) 기기 로그 권한이 없을 때 · 새 버전이 나왔을 때 알림, 카메라 섬(라이브 알림)에도 표시
- 편의 기능: 화면 더 어둡게, 자동 회전 제안 끄기, 시계에 초 표시, 기기 이름 변경, 시스템 화면 바로가기 등
- (실험적) 전원 버튼 두 번 눌러 앱 실행

## 사용 환경/준비물

대상 기기는 **OPPO Pad Mini OPD2515 / ColorOS 17 중국 내수용**입니다. 다른 기기나 펌웨어에서는 동작이 다를 수 있습니다.

서클 투 서치를 사용하려면 다음 앱을 별도로 준비해주세요.

- **[Google](https://play.google.com/store/apps/details?id=com.google.android.googlequicksearchbox)** — Google LLC에서 배포하는 앱
- **[Google Speech Recognition & Synthesis](https://play.google.com/store/search?q=google+speech+services&c=apps)** - 호환성을 위해 권장

0.3.6부터 **MiCTS는 필요 없습니다.** 설치되어 있으면 직접 실행이 실패했을 때만 예비로 사용합니다.

Google 서비스가 없는 기기는 먼저 기기의 Google 서비스와 Play 스토어를 준비해주세요. 

## 설치 및 시작하기

### 실행 방식 선택

| 방식 | 사용 방법 | 필요한 설정 |
| --- | --- | --- |
| **하단 영역 인식** · 기본값 | 하단 중앙의 투명한 인식 영역을 길게 누릅니다. | 접근성 허용 |
| **ColorOS 기본 하단 바 · 로그 감지** | ColorOS 기본 바의 제스처와 애니메이션을 사용합니다. | 접근성, 보안 설정 쓰기 권한, Breeno 비활성화, 컴퓨터에서 ADB 활성화 |
| **Gemini Assistant** | 전원 버튼을 꾹 눌러 호출합니다. | 접근성, 보안 설정 쓰기 권한, Breeno 비활성화, 컴퓨터에서 ADB 활성화 |

**하단 영역 인식**과 **ColorOS 기본 하단 바** 두 방식 중 하나를 선택해 사용합니다.
**Gemini Assistant**는 독립적으로 켜고 끌 수 있습니다.

기본 **하단 영역 인식** 방식은 태블릿만으로 설정할 수 있습니다.
**ColorOS 기본 하단 바 · 로그 감지**와 **Gemini Assistant**는 컴퓨터와 ADB가 필요합니다.

### 필수 설정

**재부팅 시 자동 시작 설정 (필수)**
1. 앱 내 **`추가 설정 → 재부팅 후 자동 복구 → 켬`**
2. 태블릿 **`설정 → 앱 → 자동 실행 → 'Circle-to-Search Trigger' → 켬`**
3. 태블릿 **`설정 → 앱 → 관련 실행 → 'Circle-to-Search Trigger' → 켬`** (OPTIONAL)
  

**배터리 제한 해제 (필수)**
1. 앱 내 **앱 정보와 절전 설정**에서 **배터리 사용량 → 백그라운드 활동 허용**을 켭니다.
   

**최근 앱 정리 제외 설정 (필수)**
1. 앱 내 **최근 앱 정리 제외 설정** 누른 후 **`최근 앱 목록(홈 버튼) → 'Circle-to-Search..' 앱 이름 누르기 → 잠금`** 후 앱 내 **`'최근 앱에 표시' 끄기`**

   

### 하단 영역 인식

1. [다운로드 페이지](https://github.com/JngVedere/OPD2515_CST/releases/latest)에서 **`Circle-to-Search-Trigger`로 시작하는 `.apk` 파일**을 받습니다.
2. 태블릿에서 APK를 열어 설치합니다. 설치가 차단되면 해당 파일을 연 앱의 **이 출처 허용**을 켭니다.
3. 앱 서랍의 **OpdCTS** 아이콘을 눌러 Circle-to-Search Trigger 설정을 엽니다. (또는 태블릿 **`설정 → 앱 → 앱 관리 → 'Circle-to-Search Trigger' → 앱 추가 설정`**)
4. **실행 방식 → 연결 앱 → 기본 어시스턴트 설정**에서 Google을 선택 및 **`앱 선택 → 서클 투 서치`**, 이후 **화면 및 앱 데이터 사용**을 **허용**합니다.
5. 태블릿 **`설정 → 앱 → 앱 관리 → 'Circle-to-Search Trigger' → 권한 → 우측 상단의 ... → 권한 제한 해제`** 경로로 Circle-to-Search Trigger 설정을 엽니다.
6. 앱 내 **접근성 설정**에서 **다운로드한 앱 → Circle-to-Search Trigger**을 켭니다.
7.  앱 내 **`실행 방식 → '하단 영역 인식' → 상단의 '사용 시작'`**
8.  앱의 연결 상태를 확인한 뒤 앱 내 **`설정 닫기`** 를 눌러 닫습니다.
9.  다른 앱을 연 상태에서 **화면 하단 중앙을 잠시 길게 누르면** 서클 투 서치가 실행됩니다.


### ColorOS 기본 하단 바 사용하기
1. **하단 영역  인식** 6단계까지 진행해주세요
2. USB 디버깅을 허용한 태블릿을 ADB가 준비된 컴퓨터에 연결합니다. (태블릿 : **`개발자 옵션 → USB 디버깅 활성화`**, PC : [ADB](https://developer.android.com/tools/releases/platform-tools?hl=ko))
3. **개발자 옵션 → Disable System Optimization → 켬**으로 세팅합니다. (옵션이 보이지 않는다면 시스템 언어를 English로 바꾸고 재시도 해주세요. 사용 시작 후에는 언어를 기존 언어로 바꿔도 됩니다.)
4. 앱 내 **추가 설정 → 최초 ADB 설정 안내**를 열고 Breeno가 꺼져있는지 확인합니다. (Breeno가 켜져 있다면 아래 명령어를 CMD나 POWERSHELL에 입력하여 비활성화합니다. 앱이 자동으로 끄지는 않습니다.)
```POWERSHELL
adb shell pm disable-user --user 0 com.heytap.speechassist
```
5. **아래 명령어**를 입력하여 권한을 부여합니다. 컴퓨터 CMD 혹은 POWERSHELL에서 실행합니다. (ADB 필요)
```POWERSHELL
adb shell pm grant --user 0 dev.padhelper.fastcts android.permission.WRITE_SECURE_SETTINGS
adb shell pm grant --user 0 dev.padhelper.fastcts android.permission.READ_LOGS
```
6. 앱 내 **`실행 방식 → ColorOS 기본 하단 바 · 로그 감지**를 선택합니다.
7. 앱 내 맨 위 **기기 로그가 연결되지 않았습니다** 안내를 눌러 **일회성 액세스 허용**을 선택합니다.
8. 앱 내 상단의 **`사용 시작`** 클릭
9. 앱의 연결 상태를 확인한 뒤 앱 내 **설정 닫기**를 눌러 닫습니다.
10. 다른 앱을 연 상태에서 **`화면 하단 중앙을 잠시 길게 누르면`** 서클 투 서치가 실행됩니다.


### Gemini Assistant 사용하기
1. **ColorOS 기본 하단 바 사용하기** 7단계까지 진행해주세요
2. 앱 내 **`전원 버튼 → 전원 버튼 길게 눌러 Gemini Assistant 열기`** 활성화
3. 앱 내 상단의 **`사용 시작`** 클릭
4. 앱의 연결 상태를 확인한 뒤 앱 내 **설정 닫기**를 눌러 닫습니다.


**태블릿을 재부팅한 후에는 로그 수집 권한을 다시 허용해야 합니다.** 재부팅 후 최초 잠금 해제 후 수 초 내에 팝업이 뜹니다.

Breeno를 비활성화하면 전원 버튼 등으로 Breeno를 여는 기능에도 영향을 줄 수 있습니다.


## 부가 기능

| 설정 | 설명 |
| --- | --- |
| **인식 영역 표시** | 설정 화면에서 하단 인식 범위를 파란색으로 보여줍니다. 설정을 벗어나면 다시 투명해집니다. |
| **터치 영역 설정** | 하단 인식 영역의 위치·크기와 인식 시간을 조절합니다. 가로/세로 화면 값을 따로 저장하며, 값을 눌러 숫자로 직접 입력할 수 있습니다. 인식 시간은 50~1000ms(기본값 195ms)이며, 짧게 줄일수록 짧은 탭도 길게 누르기로 인식될 수 있습니다. |
| **Gemini 요청 전 대기** | 전원 버튼으로 Gemini Assistant가 가끔 뜨지 않으면 늘려주세요. |
| **앱 서랍에 표시** | 앱 서랍의 OpdCTS 아이콘을 보이거나 숨깁니다. 기본값은 켜짐입니다. |
| **아이콘을 누르면** | 앱 아이콘을 눌렀을 때 열 화면을 고릅니다: 설정 화면(기본값) / 서클 투 서치 / Gemini Assistant. |
| **Search / Assistant 타일** | 빠른 설정에서 서클 투 서치와 Gemini Assistant를 바로 엽니다. **바로 실행**에서 추가합니다. |
| **Detail / Compact** | 설정 화면 오른쪽 위에서 항목 아래 부가 설명을 보이거나 숨깁니다. |
| **업데이트 확인** | 아래 **설정** 탭에 있습니다. GitHub에서 새 버전을 확인하고 앱 안에서 설치합니다. 설정을 열 때 자동으로 확인할 수도 있습니다. |
| **알림** | 아래 **설정** 탭에 있습니다. 기기 로그가 필요한 옵션이 켜져 있는데 기기 로그 권한·승인이 없을 때, 새 버전이 나왔을 때(24시간에 한 번 확인) 알림으로 알려줍니다. 둘 다 기본값은 꺼짐입니다. |
| **카메라 섬에도 표시** | 기기 로그 알림을 카메라 옆 캡슐(라이브 알림)에도 띄웁니다. 이 앱 알림 설정의 '라이브 알림에 라이브 업데이트 표시'도 켜야 합니다. '테스트'로 미리 볼 수 있습니다. |
| **편의 기능** | **설정 → 고급**에 있습니다. 화면 더 어둡게, 자동 회전 제안 끄기, 시계에 초 표시, 기기 이름 변경(온라인 인증 없이), 플래시 알림·앱 배터리 사용량·개발자 옵션 바로가기를 제공합니다. 'ADB 필요' 항목(시스템 UI 튜너, 앱 설치 프로그램 광고 제거, 전역 고주사율)은 실행할 명령을 안내합니다. |
| **최근 앱에 표시** | Circle-to-Search Trigger 설정 화면을 최근 앱 목록에 보이거나 숨깁니다. 앱서랍 아이콘에는 영향을 주지 않습니다. |
| **앱 선택** | 길게 눌렀을 때 실행할 앱을 고릅니다. 서클 투 서치로 돌아가려면 기본값을 선택하세요. |
| **사용 시작 / 끄기** | 선택한 실행 방식을 켜거나 끕니다. |
|**Google 음성 연결 다시 시작** | Gemini Assistant가 호출되지 않을 경우 이 버튼을 눌러주세요.|

## 설정 다시 열기

다음 경로 중 하나로 설정을 열 수 있습니다. 메뉴 이름은 기기 설정에 따라 조금 다를 수 있습니다.

- **앱 서랍의 OpdCTS 아이콘 누르기** (기본값. **아이콘을 누르면**을 서클 투 서치나 Gemini Assistant로 바꿨다면 아이콘을 길게 눌러 '설정'을 고르세요)
- **설정 → 앱 → 앱 관리 → Circle-to-Search Trigger → 앱 추가 설정**
- **설정 → 접근성 → 다운로드한 앱 → Circle-to-Search Trigger → 설정**
- **빠른 설정의 Circle-to-Search Trigger 타일 길게 누르기**

앱 설정의 **빠른 설정에 켜기/끄기 타일 추가**를 눌러 타일을 추가해두면 편리합니다. 앱 서랍 아이콘이나 최근 앱에서 숨겨도 위 경로로 다시 열 수 있습니다.

## 알려진 한계

1. **실행 방식 → ColorOS 기본 하단 바 · 로그 감지** 또는 **Gemini Assistant**를 사용하는 경우, 재부팅 시 로그 수집 권한을 다시 허용해야 합니다. 일반적으로 최초 잠금 해제 후 팝업이 등장하지만, 이 과정에서 예기치 못 한 오류가 발생할 수 있습니다.
2. Circle to Search의 Scroll Translate(혹은 Continuous Translate) 기능은 허용된 일부 기기에서 CSService를 통해 호출될 때에만 사용이 가능합니다. VIS 기반의 해당 프로젝트에서는 현재 이를 사용할 수 없습니다.
3. 서클 투 서치(Circle to Search)의 **화면에 관해 물어보기**를 누르면 일부 화면에서 약 **2.8초**의 전환 지연이 발생할 수 있습니다. 지연 시간은 Google 앱과 화면 내용에 따라 달라질 수 있습니다.


## 자주 묻는 질문

**Q1.최근 앱에서 ‘모두 닫기’를 누른 뒤 반응하지 않아요.**

A1.Circle-to-Search Trigger의 접근성이 켜져 있는지 확인하고, 앱 설정의 **자동 실행 설정**과 **앱 정보와 절전 설정**에서 백그라운드 실행을 허용해주세요. 필요하면 **최근 앱 정리 제외 설정** 안내에 따라 최근 앱 카드를 잠근 뒤 다시 숨길 수 있습니다.

**Q2.재부팅한 뒤 작동하지 않아요.**

A2.먼저 태블릿 잠금을 한 번 풀어주세요. 하단 영역 방식은 접근성 상태와 자동 복구 옵션을 확인하고, 기본 바 방식은 앱 안내의 ADB 활성화 명령을 다시 실행해주세요.

**Q3.‘서클 투 서치를 열지 못했습니다’가 떠요.**

A3.Google이 기본 디지털 어시스턴트로 선택되어 있는지, 화면 텍스트·스크린샷 사용이 허용되어 있는지 확인해주세요. 앱 내 **실행 방식 → 연결 앱 → 기본 어시스턴트 설정**에서 바로 확인할 수 있습니다.

**Q4.‘화면에 관해 물어보기’로 넘어갈 때 느려요.**

A4.Google 앱과 화면 내용에 따라 전환이 지연될 수 있습니다. Circle-to-Search Trigger에서 실행 방식을 바꿔도 이 지연이 해결되지는 않습니다.

**Q5.앱 삭제 후 기본 상태로 복원하려면 어떻게 하나요?**

A5. 삭제하기 전에 앱 내 **끄기**를 먼저 누르고, **전원 버튼 두 번 눌러 앱 실행**을 켜두었다면 반드시 끈 뒤 삭제해주세요. 그래도 남은 옵션은 adb로 복원해야 합니다. 
   USB 디버깅을 허용한 태블릿을 ADB가 준비된 컴퓨터에 연결합니다. (태블릿 : **개발자 옵션 → USB 디버깅 활성화**, PC : [ADB](https://developer.android.com/tools/releases/platform-tools?hl=ko))
   이후 아래 명령어를 입력해주면 기본 상태로 복원됩니다
   ```POWERSHELL
   adb shell pm enable --user 0 com.heytap.speechassist
   adb shell settings --user 0 put secure oplus_gesture_handle_cui_enable 1
   adb shell settings delete global power_button_short_press
   adb shell settings delete global power_button_double_press
   ```

**Q6.다른 기기에서 ‘기기 보호를 위해 앱 차단됨’이 뜨며 설치되지 않아요.**

A6.Google Play Protect가 접근성 권한을 요청하는 앱의 직접 설치(브라우저·파일 관리자)를 막는 경우입니다. 컴퓨터에서 ADB로 설치하면 대부분 해결됩니다.
   ```POWERSHELL
   adb install Circle-to-Search-Trigger-0.4.0.apk
   ```

**Q7.접근성에서 Circle-to-Search Trigger가 회색으로 보이고, 누르면 '앱의 액세스가 거부됨'(제한된 설정)이 떠요.**

A7.브라우저나 파일 관리자로 직접 설치한 앱에 Android가 적용하는 보호 기능입니다. 앱 서명과는 관계없고, 한 번만 허용하면 됩니다.
   1. **설정 → 앱 → 앱 관리 → Circle-to-Search Trigger**를 엽니다.
   2. 오른쪽 위 **⋮** 메뉴에서 **제한된 설정 허용**을 누르고 화면 잠금으로 확인합니다.
   3. 다시 **설정 → 접근성**에서 Circle-to-Search Trigger를 켭니다.

   메뉴가 보이지 않으면 접근성에서 한 번 켜기를 시도해 안내가 뜬 뒤 다시 앱 정보를 열어주세요. ADB로 설치한 경우(Q6)에는 이 제한이 적용되지 않습니다. 앱 설정 화면에서 접근성이 꺼져 있을 때 뜨는 안내를 누르면 앱 정보로 바로 이동합니다.

## 권한 안내

**접근성**은 하단 인식 영역과 실행 기능을 유지하는 데 사용합니다. Circle-to-Search Trigger 자체는 화면 내용을 읽거나 캡처하지 않습니다. 서클 투 서치의 화면 인식과 검색은 Google 앱이 처리합니다.

**인터넷 / 앱 설치 요청**은 앱 안의 업데이트 확인과 설치에만 사용합니다. GitHub에서 새 버전 정보와 APK만 받으며, 기기 정보는 보내지 않습니다.

**알림**은 앱의 설정 탭 → 알림에서 직접 켠 경우에만 요청하고 사용합니다. 상주 알림은 띄우지 않습니다.

**보안 설정 쓰기**는 앱이 시스템 설정을 바꿀 수 있는 강한 권한입니다. 재부팅 후 접근성 자동 복구와 하단 바 제스처 전환, 그리고 직접 켠 편의 기능(화면 더 어둡게, 회전 제안, 시계 초, 기기 이름)에 사용합니다. ColorOS 기본 바 방식에서는 이 권한과 별도 ADB 활성화가 필요합니다.

**기기 로그 읽기**는 ColorOS 기본 바와 전원 버튼 길게 누르기를 감지하는 데 사용합니다. 로그를 저장하거나 외부로 보내지 않습니다. 권한은 재부팅 후에도 유지되지만, 재부팅마다 첫 잠금 해제 뒤 Android의 확인 창에서 직접 허용해야 합니다.
